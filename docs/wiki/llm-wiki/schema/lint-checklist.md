# Checklist de LINT

- ¿Cada HECHO tiene fuente o evidencia verificable?
- ¿Existen decisiones no aprobadas presentadas como hechos?
- ¿Hay contradicciones entre PRD, restricciones, contrato y código?
- ¿Hay páginas huérfanas o enlaces rotos?
- ¿El índice refleja la estructura actual?
- ¿Hay duplicados o contenido propio de un transcript?
- ¿Hay secretos, tokens, credenciales, PII o datos reales no permitidos?
- ¿Los contratos REST tienen evidencia de ambos repositorios cuando corresponde?
