# Preferencias

## PREFERENCIA

La coordinación se guía por evidencia, trazabilidad entre especificación y pruebas, y documentación breve que no replique conversaciones completas.

Los agentes principales de API y Web se crean como guías de bootstrap y deben depurarse desde evidencia real cuando se inicialice Spring Boot o se importe el frontend generado. No deben inferir la estructura backend ni el framework frontend.
