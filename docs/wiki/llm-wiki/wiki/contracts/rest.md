# Contrato REST

## Estado

PREGUNTA ABIERTA. El PRD exige una API REST JSON consumida directamente por el frontend, pero todavía no define recursos, rutas, payloads, errores ni versionado.

## Regla de evolución

Antes de modificar un contrato se debe documentar la propuesta, identificar ambos repositorios afectados y aportar evidencia backend y frontend.
